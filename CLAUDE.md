# Floresta Sombria

Jogo 3D em JavaScript puro + Three.js (`vendor/`), sem etapa de build para desenvolver. Ver README.md.

## Depois de toda edição no jogo

O usuário joga pelo link do Artifact. Sempre que o jogo for alterado:

1. Gere o arquivo único: `node tools/build-single-html.mjs` (cria `dist/floresta-sombria.html`).
2. Republique-o no Artifact existente (mesmo link): https://claude.ai/artifact/Hgi1uJtxEht2afgbk39Acv
3. Envie o link ao usuário na resposta.

Textos do jogo e do código ficam em português.
